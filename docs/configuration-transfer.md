# 配置迁移与私钥导出

## 配置导入和导出

展开左侧栏，在左下角设置按钮右侧使用导入、导出图标：

1. 点击导出配置，默认不加密，直接选择保存位置，生成 `.pagashell` 文件。
2. 如需加密，勾选“加密”后填写至少 8 个字符的密码并确认，再导出。
3. 在另一台设备点击导入配置并选择文件。未加密文件直接校验、合并；加密文件弹出密码框，输入导出时的密码后导入。

导出内容包括服务（SSH / RDP / VNC）、按协议分类的凭证、网关（SSH / Page）、三类文件夹的嵌套层级和混合排序、服务与凭证及网关的绑定、端口映射、标签、备注，以及保存的密码、私钥、私钥口令和 Page token。

应用偏好、AI 设置与 API Key、Agent 历史、运行中的会话、端口映射的启动状态、系统保险库主密钥、已信任的 SSH 主机密钥和 RDP 证书记录不参与迁移。在新设备首次连接时仍按正常流程核验服务器身份。

### 合并规则

- 同 ID 的项目更新为文件中的信息，引用仍指向同一项目；本机独有项目保留。
- 不同 ID 的同级同名项目分别保留，导入项自动追加 ` (2)` 等编号。
- 导入项目保留文件中的同级混合顺序，本机独有项追加在各自同级末尾。重复导入同一文件不会新增副本。
- 校验文件夹循环、重复 ID、同级重名、端口及绑定关系。服务与网关不能利用共享表的 ID 跨分组覆盖。
- 文件不携带可指定的钥匙串键名。凭证密文在目标设备生成本机引用，同 ID 更新时沿用安全的现有引用。
- 在未携带密文的项目中，同 ID 且协议和认证方式未变的凭证沿用本机密文；新的项目无已存凭据，连接时按正常流程填写。
- 凭证与绑定服务的协议必须一致。旧版配置按绑定情况自动分类；跨 SSH/RDP 复用的凭证拆成独立项目，同时保留密码和绑定。

### 文件与写入

文件上限为 32 MiB，内容格式版本为 2，包含凭证协议；导入兼容版本 1。文件外层封装仍为版本 1。默认导出未加密 JSON 文件，包含明文密码、私钥及口令。勾选“加密”时，使用 PBKDF2-HMAC-SHA256（600,000 次迭代、随机 16 字节盐）派生 256 位密钥，并以 AES-256-GCM 加密和校验完整性。每次加密导出生成新的盐和 nonce；错误密码、密文篡改、未知版本或不支持的算法参数均拒绝导入。密码只用于当前操作，不保存在设置中。导入仍兼容此前没有加密标记的加密文件。

元数据使用同一个 SQLite 事务提交，保存到各项目的敏感内容通过 SecretStore 写入。写入或提交失败时回滚元数据并恢复已经改动的凭据；若系统安全存储拒绝恢复，则显示恢复失败的错误。数据库和系统安全存储之间没有跨系统事务，进程崩溃或突然断电不具备原子提交保证。

## 私钥文件导出

在私钥凭证的编辑弹框中，“导入私钥文件”旁提供“导出私钥文件”：

- 当前填入了私钥时，导出当前内容；留空时，读取并导出已保存的私钥。
- 直接保存原内容，保留 OpenSSH / PEM / PPK 格式及其原有加密状态；PPK 建议名使用 `.ppk`，其他使用 `.key`。
- 不在文件中追加私钥口令，也不把已保存的私钥预填到界面。导出不修改凭证。
- 由系统保存窗口选择位置；取消后不写入内容。macOS / Linux 在写入内容之前将目标文件权限收紧为 `600`。
