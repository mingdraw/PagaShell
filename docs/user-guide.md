## 首次连接

1. 打开左侧栏，在「服务」组的菜单中选择「新建服务」。
2. 选择协议，填写服务名称、目标地址、端口及登录信息。通常使用 SSH `22`、RDP `3389` 或 VNC `5900`，以服务器实际配置为准。
3. 如果要复用登录信息，在左侧「凭证」组先新建对应协议的凭证，再在服务中选择。SSH 支持密码或私钥，RDP 支持密码和可选的 Windows 域，VNC 只需 VNC 密码。
4. 点击「保存并连接」。以后可双击侧栏中的服务打开，或者右键选择「新建会话」单独打开一个会话。

首次 SSH 连接会显示服务器的 SHA-256 主机指纹。请与服务器管理员提供的指纹核对，再选择「信任并连接」。如果已信任的指纹变更，应用会阻止连接，请先确认服务器是否重装或更换了主机密钥。

服务表单的「高级选项」可设置标签、颜色和网关。侧栏可用文件夹归类，也可搜索名称、地址或标签。

### 命令面板与临时连接

按 `⌘K`（macOS）或 `Ctrl+Shift+K`（Windows/Linux）打开命令面板。没有会话时，也可点击欢迎页的「快速连接」。

- 搜索已保存服务，按方向键选中后回车连接。选中 SSH 服务时，`⌘Enter`（macOS）或 `Ctrl+Enter`（Windows/Linux）打开文件传输，`Shift+Enter` 新建会话。
- 临时连接输入 `ops@server.example`、`ops@server.example:2222` 或 `ssh -p 2222 ops@server.example`，选择「临时连接」并完成登录。临时连接不会加入左侧服务列表。
- 输入服务名、地址或协议（SSH、RDP、VNC），也可匹配已打开的标签和分屏。选中分屏后回车会聚焦对应窗格。输入法组词期间，回车和方向键仍用于选词。

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 下一个／上一个标签 | `Ctrl+Tab` / `Ctrl+Shift+Tab` | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| 切到第 1 至 9 个标签 | `⌘1` 至 `⌘9` | — |
| 打开并聚焦侧栏搜索 | `⌘Shift+F` | `Ctrl+Alt+F` |

标签栏放不下时，可在标签上使用滚轮横向滚动。

## SSH 终端

- **分屏**：在终端工具栏或右键菜单选择「左右分屏」或「上下分屏」。也可以把左侧栏的 SSH 服务拖到当前终端窗格的任意一边，按放置方向建立新连接。双击分隔条可平分空间。
- **切换窗格**：主标题显示当前服务的名称；混合分屏时也会列出其他服务。分屏工具栏显示当前窗格的登录地址，默认端口 22 省略。点「窗格 x/y」可按标题选择要聚焦的窗格。
- **管理窗格**：右上角的悬浮按钮可将窗格移到新标签、最大化或关闭。移到新标签时沿用原连接和终端历史；最大化后可点「还原分屏」返回。
- **同步输入**：同一标签有多个可用终端时，点「同步输入到此页签的所有窗格」。打开后，当前终端的键盘输入会同步到同标签的其他终端。多行粘贴会列出目标；最大化窗格会关闭同步。
- **查找输出**：右键选择「查找终端输出」，可搜索当前画面和回滚内容。输入关键词后，`Enter` 和 `Shift+Enter` 切换匹配，`Esc` 关闭查找。
- **终端设置**：在「设置 → 终端」调整字号和断开行为。默认保留历史输出并提示重连；开启「断开后自动关闭窗格」后，退出或断开连接会关闭对应窗格，最后一个窗格断开时关闭标签。

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 查找终端输出 | `⌘F` | `Ctrl+Shift+F` |
| 最大化或还原分屏窗格 | `⌘Shift+Enter` | `Ctrl+Shift+Enter` |
| 上一个／下一个分屏窗格 | `⌘Option+[` / `⌘Option+]` | `Ctrl+Alt+[` / `Ctrl+Alt+]` |
| 放大、缩小或重置终端字体（终端输入区聚焦时） | `⌘+` / `⌘-` / `⌘0` | `Ctrl++` / `Ctrl+Shift+-` / `Ctrl+0` |

## SFTP 文件传输

在左侧 SSH 服务或终端上右键，选择「文件传输」，应用会打开独立标签。左侧是本地文件，右侧是远程文件，可拖动中间分隔线调整宽度。

### 查找和整理文件

- **切换目录**：双击目录进入，点击路径栏中的上级目录返回。点路径栏空白处或标题行的铅笔「输入路径」，输入完整路径后按回车或点「前往路径」；按 `Esc` 取消。
- **筛选和排序**：点击标题行的放大镜「筛选当前目录」按名称查找；点列标题可按名称、大小或更新时间排序。两侧「隐藏文件」开关独立，窗格过窄时可从标题行的「…」打开「更多文件操作」。
- **目录与文本**：两侧都可从标题行或列表空白处的右键菜单「新建目录」。在同侧将选中的文件拖入目录可移动。符合条件的普通文件可右键「查看／编辑文本」，支持不超过 2 MiB 的 UTF-8 文本；文件已被其他程序改动时需重新打开后再保存。

文件列表获得焦点后，可使用以下快捷键：

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 输入路径 | `⌘L` | `Ctrl+L` |
| 筛选当前目录 | `⌘F` | `Ctrl+F` |
| 显示或隐藏隐藏文件 | `⌘Shift+.` | `Ctrl+H` |
| 刷新 | `⌘R` | `Ctrl+R` 或 `F5` |

### 上传、下载与任务进度

1. 将文件或目录从本地拖到远程进行上传，反向拖放进行下载。拖到目录行会传入该目录，拖到列表空白处会传到当前路径。也可选中文件后点工具栏的上传或下载按钮。
2. 右侧工具栏的「上传文件」「上传文件夹」可直接从系统选择器选择本地内容。传输遇到同名项时，按提示决定如何处理。
3. 点击底部「传输进度」展开任务列表。排队任务右上角显示「等待传输」，其余显示总大小，未知时显示「—」。传输中的已传大小、速率和剩余时间在路径行右侧，取消状态和失败原因也在这里。
4. 点击活动任务左侧的图标可停止该任务。失败后如可重试，任务左侧提供重试入口；支持续传时会先校验目标文件已有的内容。列表顶栏也提供全部取消、全部重试和清除已完成记录的操作。

## 运维侧板

连接 SSH 后，点击终端工具栏中的相应图标打开侧板。系统指标、进程和端口采集面向 Linux/macOS 服务器，结果取决于远端系统和当前账号的权限。

| 侧板 | 常用操作 |
|---|---|
| 服务状态 | 查看 CPU、内存、磁盘和网络等指标及趋势。可暂停自动刷新并按需手动刷新。 |
| 进程管理 | 按名称、PID 或用户搜索，按 CPU 或内存排序。查看进程详情，必要时确认后结束进程。 |
| 网络端口 | 按端口或进程搜索，按 TCP/UDP 筛选，查看 IPv4/IPv6 监听信息。点「复制进程 ID」复制关联 PID，多个 PID 以逗号分隔。 |
| Docker 管理 | 查看 Compose 编排、容器、镜像、网络和存储卷。在容器卡片的「更多容器操作 → 查看实时日志」打开日志窗口，也可按需打开容器终端。 |

混合主机分屏时，运维侧板会显示当前目标，切换窗格后可回到该主机先前的筛选和暂停状态。Docker 日志支持暂停跟随、筛选、复制和断开后重连。Docker 面板需要远端可用的 Docker CLI 和访问 Docker 服务的权限；Compose 操作还需要对应的 Compose 工具。

## 远程桌面

- **RDP**：新建 RDP 服务并填写 Windows 登录信息。连接时如出现证书确认，详情默认折叠，点「显示证书」可核对指纹。证书确认后才继续 Windows 登录。
- RDP 的「分辨率」决定远端桌面大小。按 `Ctrl+Alt+Enter` 切换全屏；全屏工具栏收起后，把鼠标移到顶部中央可重新显示并固定。
- 当 Windows 允许剪贴板重定向时，RDP 可双向复制文字、文件及文件夹。工具栏的「键入剪贴板文本」可把本机剪贴板里的文本作为键盘输入发送。详见 [RDP 远程桌面](rdp-service.md)。
- **VNC**：填写目标地址和密码即可连接标准 VNC；连接 **macOS 屏幕共享 / 远程管理**时额外填写 macOS 系统用户名即可直接登录，无需开启旧版 VNC 密码。支持键鼠、网络信号/延迟与自适应画质切换、动态分辨率（服务端支持时生效）、远端键盘/本机输入法、双向文本剪贴板同步和全屏，兼容性见 [VNC 远程桌面](vnc-service.md)。

## 网关与代理

已有 SSH 跳板机时，在左侧「网关」组创建 SSH 网关。也可[部署 Page 网关](page-gateway.md)，用 PagaGateway 让内网客户端连接中转服务器。在服务的「高级选项 → 网关」选择网关，目标的登录信息仍在服务或凭证中填写。

| 想做什么 | 在哪里操作 |
|---|---|
| 通过跳板机连接某个 SSH、RDP 或 VNC 服务 | 编辑服务，在「高级选项」中选择网关。 |
| 给本机数据库客户端等工具提供固定端口 | 在网关行选择「端口转发」，添加本地监听端口和目标地址、端口后启动。 |
| 给浏览器或其他应用提供 HTTP(S) / SOCKS5 代理 | 在网关行选择「动态代理」，设置监听端口和规则。可先用「测试代理规则」预览选路，运行后查看发送、接收速率和累计流量。详见[动态代理](dynamic-proxy.md)。 |
| 仅为 PagaShell 自己的网络请求设置代理 | 打开「设置 → 代理」，选择自动、关闭或手动配置。 |

「动态代理」默认需要在各应用内手工填写本地代理地址。若希望遵循系统代理的应用自动使用它，可在启动代理前勾选「自动设置系统网络代理」。

## Agent

1. 点击窗口顶部的 Agent 按钮展开右栏，从标题栏进入「AI 设置」。选择协议，填写 API 地址、Key 和模型 ID，测试连接后保存。
2. 在输入框输入 `@`，或点击「+」，可引用一个或多个已打开的会话。引用 SSH 会话时，相关终端输出会发送到所配置的 API，以便模型分析。
3. 默认「请求批准」模式会先显示目标、用途和命令，确认后才发送到对应 SSH 终端。使用「完全访问」时，Agent 可直接向引用的 SSH 终端发送命令。
4. 回复会随接收逐步显示，可展开「思考与工具调用」。上翻时保留阅读位置，点击「回到底部」或发新消息可恢复跟随。回复中断后会保留已收到的内容，输入框上方可查看错误并重试。标题栏的历史入口可以打开旧对话。

更多设置、权限和数据范围见 [Agent 专题](ai-agent.md)。

## 备份与更新

- **迁移设备**：使用窗口左上角的「导出配置」生成 `.pagashell` 文件，建议勾选加密；在新设备点击「导入配置」。Agent 历史、AI 设置和已信任的服务器指纹不随配置迁移。见[配置导入和导出](configuration-transfer.md)。
- **升级应用**：在「设置 → 关于」选择「检查更新」。应用内更新保留数据；Windows 和 Linux 请将应用解压在独立文件夹中。见[软件更新](software-updates.md)。
