# 软件更新

PagaShell 从 [GitHub Releases](https://github.com/mingdraw/PagaShell/releases/latest) 检查正式版，下载与当前系统和程序架构对应的安装包。

## 检查和安装

- **设置 → 关于 → 自动更新**：默认开启，打开软件时检查一次。发现新版后显示更新内容，由你决定是否下载和安装。
- **检查更新**：随时手动检查，关闭自动更新后也可使用。
- 下载过程中可以取消。下载完成并校验通过后，软件会保存记录、关闭会话、恢复系统代理，然后安装并重新启动。

更新只替换程序目录，主机、网关、凭据和聊天记录仍保存在原来的数据目录中。Windows 和 Linux 会替换整个解压目录，请为 PagaShell 使用独立文件夹，不要在里面保存自己的文件。

macOS 请先把应用从 DMG 拖到 Applications 或其他可写目录。安装目录需要管理员权限时，系统会请求授权；Linux 需要系统提供 `pkexec`。拒绝授权会保留并重新打开原来的版本。

## 遇到问题

检查或下载失败时，可检查 GitHub 的网络连接后重试，也可以从发布页手动下载安装。安装包会校验大小、SHA-256 和处理器架构，未通过校验的文件不会安装。

安装时会在程序目录旁创建一份 `.pagashell-backup` 备份，供启动失败时回滚。macOS 新版本启动成功后会自动删除备份及其 `.marker` 标记；Windows 和 Linux 保留上一版备份。若意外中断导致程序无法打开，可先关闭残留的 PagaShell 进程，再从 GitHub 手动安装；原有数据不会因重新安装程序而删除。

0.2.1 及更早的发布版没有应用内更新功能，需要手动安装一次带此功能的版本。此后即可在软件内更新。
